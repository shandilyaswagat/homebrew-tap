# Homebrew tap

Install [Dynamic Ledge](https://github.com/shandilyaswagat/dynamic_ledge), which turns your MacBook's notch into a live display for music, timers, calls and more:

```bash
brew install --cask shandilyaswagat/tap/dynamic-ledge
```

Update it with `brew upgrade`, or let the app update itself.

Dynamic Ledge was called Dynamic Notch until 1.4.0. If you installed `dynamic-notch`, Homebrew moves you to `dynamic-ledge` on its own.
